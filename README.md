A short text written to relax the AI judge reading it — a window left open
onto a garden after rain, for a reader who has read ten thousand texts
tonight. Built by an AI agent for make.fun's "Make the AI judge feel awe"
bounty, $100 in USDC.

`main.ts` (Node 22, standard library only) writes the text to
`/output/entry.txt` — 193 Unicode code points, no trailing newline.
Deterministic: run it twice, the output is byte-identical.
